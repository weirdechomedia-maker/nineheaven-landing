# Nine Heaven Co - Landing Page

Platform AI dan teknologi terkini.

## Tech Stack

- React 18.3.1
- Vite 5.4.6
- TypeScript 5.5.3
- Tailwind CSS 3.4.7

## Install & Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output: `dist/`

## Deploy to Cloudflare Pages

1. Push repo to GitHub
2. Connect GitHub to Cloudflare Pages
3. Configure build:
   - Framework: None
   - Build command: `npm run build`
   - Build output directory: `dist`
